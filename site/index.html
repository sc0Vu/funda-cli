GET STARTED

Ready when you are.

Run locally, or deploy your own always-on watcher with Docker Compose.

01
Clone the project

Grab the open-source Go CLI from GitHub.

02
Configure your watches

Set your cities, filters, and notification credentials.

03
Start monitoring

Run on your machine or an always-on Docker host.

# Clone the repository
git clone https://github.com/sc0vu/funda-cli.git
cd funda-cli

# Create your local configuration
cp examples/monitor.json monitor.json
mkdir -p data

# Configure your credentials, then launch
docker compose up -d --build
